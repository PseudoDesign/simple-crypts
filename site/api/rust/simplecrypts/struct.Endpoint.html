pub struct Endpoint { /* private fields */ }

Owned durable native endpoint; dropping it closes and wipes the native handle.

Implementations§

impl Endpoint

Source

pub fn close(self)

Explicitly closes the endpoint by consuming it. Rust ownership prevents a second close or use after close; dropping an Endpoint also closes it.

Source

pub fn initialize(config: Config<'_>) -> Result<Self, Error>

Open or create a durable endpoint with an exclusive store lock. Configuration bytes are copied by the native provider. Existing incompatible or corrupt stores fail instead of replacing identities.

Source

pub fn enrollment_enable(&mut self) -> Result<(), Error>

Persistently enable signed enrollment before registration. This mode cannot be disabled.

Source

pub fn enrollment_begin(&mut self, now: u64, expires: u64) -> Result<(), Error>

Authorize a new server enrollment session. now and expires use the same trusted server clock and application-defined units; expires must be greater than now. A fresh challenge replaces any prior candidate.

Source

pub fn enrollment_approve( &mut self, challenge: &[u8; 32], key: &[u8; 32], now: u64, ) -> Result<(), Error>

Approve the exact 32-byte challenge and candidate Ed25519 key at trusted server time now. The application must authorize the serial/session/key binding. Stale or expired approvals fail.

Source

pub fn enrollment_cancel(&mut self) -> Result<(), Error>

Cancel an unregistered server session durably. This does not revoke an enrolled peer.

Source

pub fn receive_at(&mut self, frame: &[u8], now: u64) -> Result<(), Error>

Authenticate one complete frame using trusted server time now for enrollment expiry. Accepted changes are persisted; responses remain pending for outbound transport.

Source

pub fn set_credits_issued(&mut self, total: u64) -> Result<(), Error>

Set the cumulative issued total on an enrolled server. The uint64 total must not decrease. Success commits locally and queues work; it does not deliver a frame.

Source

pub fn consume_credits(&mut self, amount: u64) -> Result<(), Error>

Consume a positive uint64 amount on an enrolled device. Insufficient credits fail with conflict; overflow fails with exhausted. The server learns consumption through a later requested report.

Source

pub fn request_credit_status(&mut self) -> Result<(), Error>

Persist a new credit report request on an enrolled server. Exchange the resulting request, response and receipt through application-owned transport.

Source

pub fn update_group( &mut self, id: u16, updates: &[(u16, ResourceValue)], ) -> Result<(), Error>

Atomically replace fields owned by this endpoint in id. Values must match the configured schema; invalid, duplicate, decreasing monotonic or wrong-owner updates fail without partial changes.

Source

pub fn request_group(&mut self, id: u16) -> Result<(), Error>

Queue and persist a resource-group snapshot request on an enrolled server. Unknown group IDs fail; no bytes are transferred automatically.

Source

pub fn inspect_group(&self, id: u16) -> Result<Value, Error>

Return a copied diagnostic snapshot of one group. Field values retain exact integer values; revision counters are decimal strings. Device-owned values on the server are last reported values.

Source

pub fn receive(&mut self, frame: &[u8]) -> Result<(), Error>

Authenticate one complete protocol frame without a trusted clock. Unapproved signed server enrollment fails closed; use receive_at during enrollment.

Source

pub fn outbound( &mut self, budget: usize, capacity: usize, ) -> Result<Option<Vec<u8>>, Error>

Generate at most one frame within budget and capacity byte limits. An idle endpoint returns no frame. Bounds failures retain pending work. Generating a frame never delivers it.

Source

pub fn inspect(&self) -> Result<Value, Error>

Return copied public-state diagnostics with uint64 counters as decimal strings. No private keys are exported, and this snapshot is not a restorable native context.

Source

pub fn fail(&mut self, operation: &str, count: u32) -> Result<(), Error>

Fixture-only injection: fail the next count storage, random or crypto operations. Zero clears the selected counter. This is not an application recovery API.

Source

pub fn fixture_revision(&mut self, revision: u64) -> Result<(), Error>

Fixture-only revision seeding for uint64 boundary tests. Requires an explicitly testing- enabled native library; production builds reject it.
