)

Inject deterministic provider failures for test fixtures.

Only storage, random and crypto operations are supported. Zero clears that injection counter. Not an application recovery mechanism.

Parameters
hHost handle; non-null except for sc_host_close().
operationNon-null injection name: storage, random or crypto.
countNumber of subsequent matching operations to fail.
Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.
