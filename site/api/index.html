The C99 core uses caller-owned bounded storage and synchronous provider callbacks. Applications own transport: producing a frame never delivers it. Each context represents one role and one peer. Serialize access externally; callbacks must not reenter that context.

Start with Initialization and public state and Durable Linux host API. Embedded integrations implement Provider callbacks and libsodium. Use Enrollment authorization and approval before Cumulative credits or Typed resource groups; exchange complete frames through Frame generation and reception. Test and fixture helpers contains test helpers, not application provisioning APIs.

Working example
The following Linux example creates a temporary server, authorizes enrollment and generates an invitation. A real application retains its private store directory and securely provisions its enrollment secret. The example does not transmit or approve anything automatically.
/* A complete, compiled Linux example. Uses fresh ephemeral secrets and a private
* temporary store; applications retain their store and provision secrets securely. */
#include "core/sc.h"
#include "providers/host/sc_host.h"
#include <sodium.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
int main(void) {
char directory[] = "/tmp/sc-api-example-XXXXXX";
char filename[128];
sc_host *server = NULL;
uint8_t secret[SC_TOKEN_BYTES], frame[SC_MAX_FRAME];
size_t length = 0;
uint64_t now = (uint64_t)time(NULL); /* This application uses seconds. */
int status = SC_ERR_STORAGE;
if (sodium_init() < 0 || !mkdtemp(directory)) {
return 1;
}
randombytes_buf(secret, sizeof secret);
status = sc_host_initialize(SC_SERVER, directory, "example-device", secret,
NULL, NULL, 0, &server);
sodium_memzero(secret, sizeof secret);
if (status == SC_OK) {
status = sc_host_enrollment_enable(server);
}
if (status == SC_OK) {
status = sc_host_enrollment_begin(server, now, now + 600);
}
if (status == SC_OK) {
status = sc_host_outbound(server, sizeof frame, frame, sizeof frame, &length);
}
if (status == SC_OK) {
printf("Generated %zu invitation bytes; transport sends them separately.\n", length);
} else {
fprintf(stderr, "%s\n", sc_host_status(status));
}
sc_host_close(server); /* Release the lock and wipe the in-memory identity. */
snprintf(filename, sizeof filename, "%s/state.bin", directory);
unlink(filename);
snprintf(filename, sizeof filename, "%s/state.lock", directory);
unlink(filename);
rmdir(directory); /* Only this example deletes its temporary identity. */
return status == SC_OK ? 0 : 1;
}

Provider contract
Callback inputs are borrowed for the synchronous call; never retain stack or output buffers. The provider's user state and schema descriptors must outlive the context. Report success only after outputs are complete. Do not publish partial results from failed callbacks.

Commit compares the durable generation, atomically replaces the encoded record and advances the generation. Generation zero denotes absence. Reserve persists the nonce high-water mark before success. An uncertain storage outcome must fail closed until normal reload reconciles it; never roll back reservations. Reinitialize with sc_init(), never a copied sc_context or restored runtime nonce cursor. Private keys remain inside the provider.

Enrollment and time
Signed enrollment requires explicit server authorization and approval of the exact serial/session/key binding. The application supplies trusted server time in consistent units and chooses the expiry interval. sc_receive() has no trusted time and fails closed for unapproved signed server sessions; use sc_receive_at() instead.
Credits and reporting
Credits issued and consumed are cumulative uint64 totals. Consumption changes the device's local state. The server sees the last reported consumption until a request, response and receipt exchange completes. Neither setters nor requests perform transport I/O.
