Generate one pending frame within a byte budget.

Does not deliver the frame. Returns SC_NO_OUTPUT when idle; output length is initially zero. Budget/capacity failures do not consume pending output. Successful encrypted output durably reserves nonces before use. Transport loss may require retransmission; never restore runtime nonce cursors.

Parameters
ctxNon-null context; initialized except when passed to sc_init().
byte_budgetMaximum permitted output frame size, in bytes.
frameNon-null frame buffer; borrowed for this call.
capacityWritable buffer capacity, in bytes.
lengthNon-null destination for the frame byte count; zero when no frame is returned.
Returns
SC_OK with a frame, SC_NO_OUTPUT when idle, or a sc_status error.

Process one complete incoming protocol frame without trusted time.

Equivalent to sc_receive_at() with UINT64_MAX. An unapproved signed server enrollment therefore fails closed; use sc_receive_at() during enrollment. Link framing such as COBS is the caller's responsibility.

Parameters
ctxNon-null context; initialized except when passed to sc_init().
frameNon-null frame buffer; borrowed for this call.
lengthComplete input frame length, in bytes.
Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.

Authenticate and process one complete incoming protocol frame.

The server uses trusted time to enforce signed enrollment expiry. Accepted state changes are committed before success. Responses remain pending for sc_outbound(); this call never sends them.
