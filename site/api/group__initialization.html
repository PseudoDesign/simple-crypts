◆ sc_init()

sc_status sc_init ( sc_context *  ctx,
const sc_config *  config,
const sc_provider *  provider 
)

Initialize caller-owned storage or restore an existing record.

Loads through the provider; only SC_NOT_FOUND creates a zero-valued record. Configuration and callback tables are copied, but referenced schemas and provider resources must outlive the context. Never restore raw context memory. A failed initialization leaves the context unusable.

Parameters
ctxNon-null context; initialized except when passed to sc_init().
configNon-null role, serial, identity and schema configuration.
providerNon-null synchronous provider callbacks and their user data.
Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.
