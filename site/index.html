      What this demonstrates
      Private contents. Visible delivery. The host can read signed challenges and public routing information. Device responses and confirmations are encrypted. Endpoint panels show each endpoint’s own knowledge; they are not a host decryption view.
      Agreement needs delivery. Cryptography detects tampering; it cannot make the host forward a message. Updates stay pending until the required authenticated report or receipt arrives.
      A local simulation with real code. Both endpoints run in this tab, each in its own worker. Reboot preserves simulated storage; refresh or Reset starts fresh. This is not a hardware keystore or a production server.
