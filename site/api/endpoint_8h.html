Detailed Description

Persistent browser bridge, owned by one worker and one Wasm instance.

All mutating calls require successful initialization and exclusive access. Await Asyncify completion: storage success follows IndexedDB commit. Failures leave the instance closed to further mutation when durability is uncertain.
