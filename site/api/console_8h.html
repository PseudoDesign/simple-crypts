◆ device_command()

int device_command ( void  )

Parse the input line and execute a local command on the initialized device. The worker must await durable storage completion before inspecting output. A sync result requests transport from the worker; this call never transfers frames.

Returns
0 local success, 1 quit, 2 error with output text, or 3 transport requested.
