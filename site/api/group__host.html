Requires the credits schema. Returns SC_ERR_CONFLICT when the resulting consumption exceeds issued credits, SC_ERR_EXHAUSTED on uint64 overflow, and SC_ERR_ARGUMENT for zero. Open or create an exclusively locked durable endpoint store.

Owns allocated memory and software keys until sc_host_close(). Creates missing stores, but rejects incompatible, corrupt or mismatched stores. Supplied strings and key bytes are copied. Storage failures after uncertain writes poison the handle; close it and reopen through normal initialization.

Parameters
roleSC_DEVICE (1) or SC_SERVER (2).
storageNon-null path to a private store directory owned by the current user.
serialNon-null printable ASCII serial of 1 through SC_MAX_SERIAL bytes.
secretNon-null 32-byte enrollment secret; must match an existing store.
seedOptional 32-byte provisioning seed; NULL generates a fresh identity for a new store.
server_keyRequired 32-byte pinned Ed25519 server public key on devices; ignored for servers.
random_unavailableNonzero simulates unavailable entropy for tests; use zero in applications.
outNon-null handle destination; set to NULL before initialization and owned by the caller on success.
Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.

int sc_host_outbound ( sc_host *  h,
size_t  budget,
uint8_t *  frame,
size_t  capacity,
size_t *  n 
)

Generate one pending frame within a byte budget.

Does not deliver the frame. Returns SC_NO_OUTPUT when idle; output length is initially zero. Budget/capacity failures do not consume pending output. Successful encrypted output durably reserves nonces before use. Transport loss may require retransmission; never restore runtime nonce cursors. See sc_outbound(). The handle owns its context and durable provider.

Parameters
hHost handle; non-null except for sc_host_close().
budgetMaximum permitted output frame size, in bytes.
frameNon-null frame buffer; borrowed for this call.
capacityWritable buffer capacity, in bytes.
nNon-null destination for the output byte count; zero when no frame is returned.
Returns
SC_OK with a frame, SC_NO_OUTPUT when idle, or a sc_status error.

int sc_host_update_group ( sc_host *  h,
uint16_t  id,
const uint8_t *  data,
size_t  size 
)

Apply typed field records as one atomic update.

Each record contains a big-endian uint16 field ID, one-byte type, one-byte length, and value bytes. Numeric values use eight big-endian bytes; Boolean values use one byte; text is UTF-8 without a NUL terminator. Uses the same validation and persistence as sc_data_update_group(). See sc_data_update_encoded(). The handle owns its context and durable provider.

Parameters
hHost handle; non-null except for sc_host_close().
idResource group ID from the configured schema.
dataNon-null encoded typed-record input.
sizeInput byte count.
Returns
SC_OK on success, SC_NOT_FOUND for an unknown group, or a negative sc_status.
