Try it

  1. Create device, then Authorize enrollment in its fleet row.
  2. Run status in its console to compare its key with Enrollment identity, then Approve device.
  3. Set issued total to 100. The device receives its credits and replies.
  4. Type consume 25, then status to see its remaining balance.
  5. Request report in the table to update the last reported consumption.

Type help for commands. Use ↑ / ↓ for command history. Hide a console and reopen it from the fleet; its device keeps running.
