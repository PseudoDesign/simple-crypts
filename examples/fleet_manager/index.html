Using a physical QT Py

Connect a board running the Simple Crypts demo, choose Register QT Py, then review its identity and approve it in the table. Press BOOT on the board to consume credits; Request report refreshes the balance. USB disconnection does not power off the board.

Keep the same browser profile and site address. Registrations from the separate QT Py page appear here automatically. A board enrolled by the Python operator or another host must be factory-reset before registering here; resetting erases its identity and credits.

After a reboot, connect USB and request a report to resume. Use Chrome or Edge over HTTPS or localhost. No background polling or automatic factory reset is performed.

Try a simulated device

  1. Create device, then Authorize enrollment in its fleet row.
  2. Run status in its console to compare its key with Enrollment identity, then Approve device.
  3. Set issued total to 100. The device receives its credits and replies.
  4. Type consume 25, then status to see its remaining balance.
  5. Request report in the table to update the last reported consumption.

Type help for commands. Use ↑ / ↓ for command history. Hide a console and reopen it from the fleet; its device keeps running.

Reset saved simulated devices?

This deletes simulated device identities, credit balances, and connection settings in this browser, including retired external-device records. This cannot be undone. QT Py host registrations and physical boards are unchanged.
