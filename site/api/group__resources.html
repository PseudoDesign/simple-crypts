Encode all current values of a group.

Uses schema field order and the typed record format accepted by sc_data_update_encoded(). Sets output length to zero before validation; insufficient capacity leaves the output buffer unchanged.

◆ sc_data_update_encoded()

sc_status sc_data_update_encoded ( sc_context *  c,
uint16_t  id,
const uint8_t *  bytes,
size_t  n 
)

Apply typed field records as one atomic update.

Each record contains a big-endian uint16 field ID, one-byte type, one-byte length, and value bytes. Numeric values use eight big-endian bytes; Boolean values use one byte; text is UTF-8 without a NUL terminator. Uses the same validation and persistence as sc_data_update_group().

Parameters
cNon-null initialized context.
idResource group ID from the configured schema.
bytesNon-null typed-record input buffer; borrowed for this call.
nInput byte count, greater than zero.
Returns
SC_OK on success; otherwise a sc_status error or SC_NOT_FOUND for an unknown group.

sc_status sc_data_update_group ( sc_context *  c,
uint16_t  id,
const sc_data_update *  updates,
size_t  count 
)

Atomically update fields owned by this endpoint.

Requires confirmed enrollment. Duplicate or unknown fields, wrong ownership, invalid values and decreasing monotonic counters are rejected. Changed values are committed before success; server updates queue a request. Device updates await a request to be reported.

Parameters
cNon-null initialized context.
idResource group ID from the configured schema.
updatesNon-null array of count field updates; borrowed for this call.
countNumber of array elements.
Returns
SC_OK on success; otherwise a sc_status error or SC_NOT_FOUND for an unknown group.
