3 · Try credits

Press and release BOOT to consume one credit. Green means success; three red flashes mean failure. Refresh balance to see button presses. No background polling is performed.

Keep this browser’s saved data

The server identity is saved in this browser profile for this site address. Return to the same address and profile to reconnect. Clearing site data loses the host identity; private browsing is not suitable for a lasting enrollment.

A board already registered by the Python operator or another browser must be managed there, or factory-reset before registering here. Reset erases identity and credits. This page never resets the board automatically.

To factory-reset the demo, hold BOOT for five seconds. If it enters RPI-RP2 mode, release BOOT and tap RESET. Reconnect here and register again. After any ordinary reboot, Refresh balance supplies fresh startup entropy and resumes the saved enrollment.
