sc_status sc_consume_credits ( sc_context *  c,
uint64_t  amount 
)

Consume a positive amount on an enrolled device.

Requires the credits schema. Returns SC_ERR_CONFLICT when the resulting consumption exceeds issued credits, SC_ERR_EXHAUSTED on uint64 overflow, and SC_ERR_ARGUMENT for zero. Commits locally; the server learns consumption through a later report.

Parameters
cNon-null initialized context.
amountPositive number of credits to consume.
Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.

Validate the two-field credits invariant.

Requires two values in issued/consumed schema order. Returns SC_OK when consumed does not exceed issued, otherwise SC_ERR_CONFLICT. Called by the generated credits schema validator.

Parameters
vNon-null array of credit values in schema field order.

Returns
SC_OK for valid credits, otherwise SC_ERR_CONFLICT.

Set cumulative credits issued by an enrolled server.

The total must not decrease. This is a cumulative total, not an increment. Requires the credits schema; commits through sc_data_update_group() and queues protocol work.

Parameters
cNon-null initialized context.

Returns
SC_OK on success; otherwise a sc_status error. Provider failures propagate.
