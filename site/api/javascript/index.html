Javascript API

Endpoints have one owner. Mutations persist through the host or browser provider; transport remains application-owned. Fixture helpers are for testing only.

module:examples/common/endpoint.Endpoint

module:examples/common/endpoint.Endpoint(module)

Wrap a Wasm module already owned by the calling worker. Use open for initialization. module: Emscripten module instance.

module:examples/common/endpoint.Endpoint#call

module:examples/common/endpoint.Endpoint#call(name, types, args)

Await an exported mutation, including storage completion; native errors reject. name: Export name. types: Emscripten argument types. args: Argument values. Returns: Nonnegative native status.

module:examples/common/endpoint.Endpoint#console

module:examples/common/endpoint.Endpoint#console(line, now)

Run the C++ command parser after copying a UTF-8 input line. line: At most 4096 UTF-8 bytes without NUL. now: Trusted server time in seconds. Returns: Copied output and quit/error/sync flags; the worker handles transport.

module:examples/common/endpoint.Endpoint#outbound

module:examples/common/endpoint.Endpoint#outbound()

Generate and copy one pending frame, awaiting nonce reservation before success. Returns: Owned bytes, or null when idle. Never delivers the frame.

module:examples/common/endpoint.Endpoint#put

module:examples/common/endpoint.Endpoint#put(bytes, offset)

Copy bytes into the shared 4096-byte bridge input; callers serialize access. bytes: Input bytes. offset: Byte offset.

module:examples/common/endpoint.Endpoint#receive

module:examples/common/endpoint.Endpoint#receive(frame, now)

Authenticate a complete frame and await durable state updates. frame: Between 1 and 512 bytes. now: Trusted server time in seconds. Returns: Completion; failures reject.

module:examples/common/endpoint.Endpoint#server

module:examples/common/endpoint.Endpoint#server(command, args, now)

Apply a fleet control to this server, persisting pending work without delivery. command: begin, cancel, approve, issue, or request. args: Challenge/key for approval or decimal total for issuance. now: Trusted server time in seconds; enrollment lasts 600 seconds. Returns: ok on success; errors reject.

module:examples/common/endpoint.Endpoint#state

module:examples/common/endpoint.Endpoint#state()

Copy public diagnostics; uint64 values remain decimal strings. Returns: Public state or null when unavailable.

module:examples/common/endpoint.Endpoint#values

module:examples/common/endpoint.Endpoint#values(values)

Write exact uint64 slots at input offset 2048; avoids Asyncify i64 argument rewind. values: At most two values in the uint64 range.

module:examples/common/endpoint.Endpoint.open

module:examples/common/endpoint.Endpoint.open(factory, storage, role, serial, pin, fresh)

Create an isolated instance and await initialization from durable storage. Missing or incompatible saved state rejects. factory: Emscripten module factory. storage: Awaitable load/save callbacks. role: Device or server role. serial: Validated serial. pin: Hexadecimal 32-byte server public key. fresh: Require a new identity. Returns: Initialized, exclusively owned endpoint.

module:examples/common/endpoint.uint64

module:examples/common/endpoint.uint64(text)

Parse an exact unsigned decimal uint64 without converting through Number. text: Decimal digits only. Returns: The exact value; malformed or overflowing input throws.

module:examples/common/endpoint.validSerial

module:examples/common/endpoint.validSerial(serial)

Validate a serial before creating storage or identity state. serial: Between 1 and 32 printable non-space ASCII bytes. Returns: The validated serial; invalid input throws.

module:examples/common/storage.clearFleet

module:examples/common/storage.clearFleet(db)

Delete all fleet and endpoint records in one durable transaction. db: Open database; caller must stop endpoint instances first. Returns: Completion; aborts reject without reporting success.

module:examples/common/storage.endpointStorage

module:examples/common/storage.endpointStorage(db, serial, role, fresh)

Create callbacks for one endpoint namespace. Persist encoded records and nonce high-water marks, never raw native context memory. db: Open database. serial: Validated device serial. role: Device or server namespace. fresh: Whether initialization requires an absent endpoint record. Returns: Asynchronous read/write callbacks used by the Wasm provider.

module:examples/common/storage.openDatabase

module:examples/common/storage.openDatabase()

Open the versioned browser database; incompatible or failed stores reject instead of replacing identities. The owning worker holds the fleet Web Lock. Returns: Open database connection.

module:examples/common/storage.transaction

module:examples/common/storage.transaction(db, store, mode, operation)

Run one object-store operation and resolve only after transaction completion. db: Open database. store: Object store name. mode: Access mode. operation: Callback returning an IDBRequest. Returns: Request result after durable completion; aborts reject.

module:examples/fleet_manager/transport.exchange

module:examples/fleet_manager/transport.exchange(server, device, now, log)

Deliver pending opaque frames between connected simulated endpoints until idle or awaiting enrollment approval. server: Server endpoint. device: Running device endpoint, or null when stopped. now: Trusted server time for enrollment expiry. log: Observer for completed transfer messages. Returns: Completion; rejected frames or nonconvergence throw.

module:web/endpoint.Endpoint

module:web/endpoint.Endpoint#state

module:web/endpoint.unhex

Decode exactly one 32-byte public key from hexadecimal. text: A 64-character hexadecimal key. Returns: Fresh key bytes; malformed input throws.
